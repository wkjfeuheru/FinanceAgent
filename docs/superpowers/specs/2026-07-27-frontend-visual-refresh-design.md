# 金融投顾前端视觉焕新设计

## 目标

在不改变现有业务功能、API、登录流程和移动端侧栏逻辑的前提下，重新设计登录页与投顾工作台，使界面从传统蓝白后台升级为可信、克制、具有数据结构感的现代金融产品。

## 设计系统

采用 Technical Minimalist 风格：纸张白 `#F7F7F5` 为主背景，深森林绿 `#1A3C2B` 为品牌色，使用低透明度深灰细线划分结构。强调色仅使用珊瑚、薄荷绿和柔和金色。界面保持扁平，不使用厚重阴影、霓虹或装饰性渐变。

中文正文使用系统无衬线字体，标题使用紧凑的几何无衬线风格，小标签、状态和数据元信息使用等宽字体风格。圆角控制在 0–4px，以结构线、留白和字号层级建立视觉秩序。

## 页面结构

### 登录页

保留登录/注册双态。左侧展示产品定位、可信能力和简洁的金融数据结构图，右侧使用带角标记的登录表单。移动端收敛为单列，品牌说明简化但不隐藏核心信任信息。

### 投顾工作台

保留顶部品牌栏、聊天主区、用户画像与会话历史。桌面端将其组织为清晰的网格：对话区继续占主要空间，右侧画像和历史用细线分区；输入框固定在底部，分析步骤、状态和配置指标使用结构化数据样式。移动端保留右侧抽屉。

## 画布方案

先在 Superdesign 中忠实还原当前工作台作为 Ground Truth，再从还原稿分支两套方案：

1. 现代机构投顾：低信息噪声、高留白、强调信任与阅读舒适度。
2. 数据化智能终端：同一设计系统下提高信息密度，强化实时状态、分析步骤和指标。

用户在画布中选择方案后才修改 Vue 代码。

## 约束与验证

- 保留全部中文功能文案和 Element Plus 图标语义，不使用 emoji。
- 不改变前后端公开接口和聊天流式事件处理。
- 桌面端、768px 抽屉布局及 480px 登录页均需验证。
- 实现后运行 `npm run build`，并对登录页、空对话、对话中、分析进度及侧栏状态进行视觉检查。
