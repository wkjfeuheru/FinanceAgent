# 中国股票主题分类来源调研

更新时间：2026-09-11

本文回答一个具体问题：主题候选池的初始线索应从哪里获得，哪些来源适合通过程序接入，哪些来源只能作为人工核验或最终证据。结论按“授权分类发现”和“官方事实核验”分层；不把网页上能看到的板块标签直接当作可再分发的数据授权。

## 结论

推荐采用两层来源：

1. **主发现源：购买中证指数或申万研究的正式数据授权。** 中证官网明确提供“行业分类信息”“证券所属指数检索”“数据服务”和“授权资讯商”入口；这类源的优势是有稳定分类口径、证券代码映射和可记录的版本/更新日期。中证行业分类查询入口见[中证行业分类信息](https://www.csindex.com.cn/#/dataService/industryClassification)，其官方页面说明该功能用于查询证券所属中证行业分类；数据产品和授权入口见[中证数据服务](https://www.csindex.com.cn/#/dataService/introduction)及[授权资讯商](https://www.csindex.com.cn/#/dataService/vendor)。
2. **最终证据源：交易所和巨潮的公司公告、定期报告及监管披露。** 上海证券交易所提供[最新公告](https://www.sse.com.cn/disclosure/listedinfo/announcement/)，深圳证券交易所提供[上市公司公告](https://www.szse.cn/disclosure/listed/notice/index.html)，巨潮资讯网明确自称“中国证监会指定的上市公司信息披露网站”，并提供公告检索与披露页面，见[巨潮首页](https://www.cninfo.com.cn/new/index)。这些来源适合保存 `source_uri`、公告日期、标题和证据摘录，用于管理员将发现线索审核为 `active`。
3. **没有商业分类授权时的启动方案：** 允许接入同花顺 iFinD/量化接口或东方财富 Choice 的正式账户作为临时发现源，但必须使用供应商授权的 API/SDK，不抓取网页接口，不把其结果自动激活。它们只能生成 `pending` 线索，且须保留供应商名称、产品版本、查询时间和原始响应哈希。
4. **不建议将公共网页或 LLM 作为生产主题源。** 公开页面可以帮助人工定位公告，但不能证明有批量、持续、可再分发的授权；LLM 只能解释已计算事实，不能决定主题成员或行动结论。

## 逐项依据和接入边界

### 中证指数

中证官网导航同时列出“指数数据服务”“证券所属指数检索”“行业分类信息”和“授权资讯商”，这说明中证把分类查询与授权数据服务区分开。实际接入应优先采购正式数据产品，在适配器中记录：`provider_name`、分类体系、版本/发布日期、证券代码、查询时间、原始响应哈希和许可编号。公开网页查询只能用于小规模人工核验，不能据此实现网页批量抓取。

### 申万

申万研究官网的[行业/策略指数栏目](https://www.swsresearch.com/institute_sw/strategy_index/)是官方入口，但公开网页没有给出可直接承诺的开放 API、频率或再分发条款。因此在未取得书面数据字典和授权前，项目不能把非官方 SDK、网页接口或第三方镜像当生产 Provider。签约时至少确认：行业层级、股票映射、历史版本、调整生效日、请求配额、内部使用/对外展示范围。

### 同花顺与 Choice

两者都适合“有合同的发现适配器”，不适合通过免费网页做生产数据源。同花顺官方数据接口页明确列出 Windows/Linux 下的 Python 接口，并提供登录、申请试用和下载/帮助入口；Choice 官方站明确列出 Choice 数据库、量化接口和商业定制产品。上述信息只能证明存在正式产品和接入渠道，不能证明当前账号拥有主题字段或再分发权，所以配置前必须获取字段清单和授权确认。

### 交易所与巨潮

交易所公告和巨潮披露是成员审核的事实层。建议审核规则要求证据至少包含：官方 URI、证券代码、披露日期、与主题相关的原文摘录；对“概念相关”但无公司正式披露的线索保持 `pending`，不能仅凭供应商标签激活。证据表不应保存整站镜像，只保存必要摘录、哈希、抓取时间和原始链接。

## 对本项目的落地建议

当前代码约定的 `ThemeDiscoveryProvider` 可以保持不变，新增供应商适配器时统一转换为 `ThemeLead`：

```text
licensed classification provider
    -> ThemeLead(source_class=licensed_classification)
official disclosure lookup
    -> evidence candidate / reviewer link
admin review
    -> pending -> active
```

建议配置项按供应商区分，避免继续使用一个含义过宽的 `THEME_DISCOVERY_ENDPOINT`：

```text
THEME_DISCOVERY_PROVIDER=csi|sws|ifind|choice
THEME_DISCOVERY_LICENSE_ID=...
THEME_DISCOVERY_ENDPOINT=...
THEME_DISCOVERY_API_TOKEN=...
THEME_DISCOVERY_TIMEOUT=15
```

未完成授权或无法取得稳定主题成员映射时，系统应保持“只产生待审核线索”的降级状态；不得写入占位评分、不得自动激活、不得把供应商标签宣称为公司已披露事实。

## 采购/接入前检查清单

- 获取供应商官方字段字典和服务协议，确认包含主题/行业成员、历史回溯、更新频率和调用配额。
- 确认许可证允许内部研究、管理员审核和面向用户展示哪些字段；分别确认是否允许保存原始响应、证据摘录和哈希。
- 让供应商提供测试账号或沙盒，验证一个主题至少返回 5 个可映射的 A 股代码。
- 将分类体系版本、查询时间和响应哈希写入 `theme_evidence`，确保结果可重放。
- 用交易所/巨潮公告复核每个拟激活成员；无法找到充分官方证据的记录保持 `pending` 或 `rejected`。
- 在真实冷启动前完成管理员审核，不以 Provider 返回成功作为自动激活条件。
