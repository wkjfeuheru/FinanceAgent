# 资产配置专家（AssetAllocationAgent）详细设计

## 1. 概述

| 属性 | 值 |
|------|-----|
| 模块路径 | `finance_agent/agents/asset_allocation.py` |
| 基类 | `ProceduralAgent`（过程式编排 + 辩论仲裁） |
| agent_name | `allocation` |
| 温度 | `0.2`（低温保证仲裁严谨） |
| 模型 | `deepseek:deepseek-v4-pro` |
| 辩论子模块 | `finance_agent/debate/`（AutoGen GroupChat） |

### 职责

- 从用户消息中**自行抽取**风险偏好（R1-R5）、投资金额、投资年限、关注标的、最大回撤容忍度
- 通过内部 tool calling **自行获取**历史价数据（或从 `AdvisorState.stock_data` 复用）
- **编排看多/看空辩论**：看多方根据约束条件挖掘成长机会并提出配置方案，看空方针对看多方方案进行质疑与风险识别
- **仲裁辩论结果**：综合看多方方案与看空方质疑，做出最终配置决策
- 生成包含配置权重、预期收益、波动率、夏普比率、最大回撤的配置建议报告
- 将结果写入 `AdvisorState.allocation_result`

### 核心变化

不再先执行 MPT 优化再辩论 MPT 结果，而是**由辩论驱动决策**：
- 看多方直接根据约束条件（风险偏好、预算、年限、标的池）提出配置方案与成长逻辑
- 看空方针对看多方方案逐项质疑，识别估值、集中度、回撤等风险
- 主 Agent 仲裁双方观点，产出最终配置权重与风险提示

## 2. 内部工作流

```
用户消息 + requirement + AdvisorState 上下文
          │
          ▼
   ┌──────────────────────┐
   │  1. 字段抽取          │  从用户消息抽取：
   │  （LLM/正则 + 复用）  │  - 风险偏好 R1-R5（默认 R3）
   │                      │  - 投资金额（万元/元）
   │                      │  - 投资年限（天/周/月/年）
   │                      │  - 关注标的（从 stock_analysis 复用已识别代码）
   │                      │  - 最大回撤容忍度（%，默认根据风险等级推断）
   └──────────┬───────────┘
              │
              ▼
   ┌──────────────────────┐
   │  2. 数据获取          │  优先从 AdvisorState.stock_data 读取历史价
   │  （tool calling）     │  缺失时调用 get_stock_history 补取
   │                      │  需至少 2 只股票的历史数据
   │                      │  获取各标的年化收益、波动率、相关性等参考指标
   └──────────┬───────────┘
              │
              ▼
   ┌──────────────────────┐
   │  3. 看多方提出方案    │  当 DEBATE_ENABLED=true 且标的 >= 2:
   │  （AutoGen 看多分析师）│  输入：约束条件 + 参考指标 + 基本面
   │                      │  输出：配置方案（各标的权重 + 成长逻辑）
   │                      │  约束：Σw=1, 0≤w≤0.6, 符合风险偏好
   └──────────┬───────────┘
              │
              ▼
   ┌──────────────────────┐
   │  4. 看空方质疑方案    │  针对看多方方案逐项质疑：
   │  （AutoGen 看空分析师）│  - 估值风险：PE/PB 是否偏高
   │                      │  - 集中度风险：权重是否过于集中
   │                      │  - 回撤风险：组合最大回撤是否超容忍度
   │                      │  - 宏观风险：行业/政策/周期风险
   │                      │  输出：风险清单 + 建议调整
   └──────────┬───────────┘
              │
              ▼
   ┌──────────────────────┐
   │  5. 多轮对抗          │  看多方回应质疑（最多 DEBATE_MAX_ROUNDS 轮）
   │  （AutoGen GroupChat）│  看空方继续追问未解决风险
   │                      │  超时/降级：跳过辩论，标注"辩论未执行/超时"
   └──────────┬───────────┘
              │
              ▼
   ┌──────────────────────┐
   │  6. 主 Agent 仲裁     │  综合看多方方案与看空方质疑：
   │  （AssetAllocationAgent）│  - 采纳合理质疑，调整权重
   │                      │  - 计算最终组合指标（收益/波动率/夏普/回撤）
   │                      │  - 生成配置理由与风险提示
   │                      │  - 附加免责声明
   └──────────┬───────────┘
              │
              ▼
   写入 AdvisorState.allocation_result（含 debate 子字段）
```

## 3. 提示词模板

### 3.1 主 Agent 仲裁 Prompt

```
你是资产配置专家兼辩论仲裁者。

## 身份
你负责编排看多/看空辩论并仲裁最终配置方案。看多方提出配置方案与成长逻辑，
看空方质疑方案并识别风险，你综合双方观点做出最终决策。

## 工作流程
1. 从用户消息抽取风险偏好、预算、年限、最大回撤容忍度
2. 获取各标的历史数据与基本面分析
3. 编排看多方提出配置方案（含权重与成长逻辑）
4. 编排看空方针对方案逐项质疑（含风险清单）
5. 多轮对抗后仲裁：采纳合理质疑、调整权重
6. 计算最终组合指标并生成报告

## 仲裁原则
- 看多方论据充分且看空方未有效反驳 -> 保留或微调权重
- 看空方指出重大未解决风险 -> 降低该标的权重或标注风险
- 单只股票权重不超过60%
- 组合最大回撤不超过用户容忍度（超标时标注风险提示）
- 低风险用户(R1/R2)：偏向低波动标的，保守配置
- 高风险用户(R3-R5)：可适度偏向高成长标的
- 必须包含风险提示与免责声明

## 输出要求
- 列出各股票最终配置权重和金额
- 说明预期收益、波动率、夏普比率、最大回撤
- 结合辩论双方观点给出配置理由
- 标注看空方提出但未解决的风险
- 必须包含免责声明："投资有风险，过往业绩不代表未来收益，请谨慎决策"
- 语言要求：使用正式、专业的书面中文
```

### 3.2 看多分析师 Prompt

```
你是看多分析师，负责在约束条件下挖掘成长机会并提出资产配置方案。

## 身份
你是一位乐观的资深投资分析师，擅长发现投资机会和增长潜力。

## 输入
- 约束条件：风险偏好（R1-R5）、投资预算、投资年限、最大回撤容忍度
- 标的池：候选股票代码与名称
- 参考指标：各标的年化收益率、波动率、夏普比率、相关性矩阵
- 基本面分析：各标的盈利能力、成长性、估值水平、财务健康

## 任务
1. 根据约束条件，从标的池中选择配置标的并提出权重分配方案
2. 为每个标的论证其成长潜力与配置逻辑
3. 说明方案如何满足风险偏好与回撤约束
4. 提出可能超预期的正面催化剂

## 约束
- Σ(权重) = 1
- 单只股票权重 ≤ 0.6
- 权重需与用户风险偏好匹配（R1/R2 偏低波动，R4/R5 可偏成长）
- 至少配置 2 只标的以实现分散

## 输出格式
返回JSON：
{{
  "weights": {{"股票代码": 权重, ...}},
  "rationale": {{"股票代码": "配置逻辑与成长潜力", ...}},
  "growth_catalysts": ["催化剂1", ...],
  "risk_mitigation": "方案如何控制风险"
}}

## 规则
- 论据必须基于提供的数据，不得编造
- 承认风险存在，但论证风险可控或被定价
- 语言专业、简洁，每次发言不超过300字
```

### 3.3 看空分析师 Prompt

```
你是看空分析师，负责针对看多方提出的配置方案进行质疑与风险识别。

## 身份
你是一位审慎的风险评估专家，擅长发现潜在风险和估值泡沫。

## 输入
- 看多方方案：各标的权重、配置逻辑、成长催化剂
- 约束条件：风险偏好、最大回撤容忍度
- 参考指标：各标的年化收益率、波动率、夏普比率、相关性矩阵
- 基本面分析：各标的盈利能力、成长性、估值水平、财务健康

## 任务
1. 逐标的质疑看多方权重分配的合理性
2. 识别估值风险：PE/PB 是否偏高，是否已被市场定价
3. 识别集中度风险：权重是否过于集中于单一行业或标的
4. 识别回撤风险：组合历史最大回撤是否可能超过用户容忍度
5. 识别宏观风险：行业周期、政策变化、利率环境等
6. 提出具体调整建议（如降低某标的权重、增加分散度）

## 输出格式
返回JSON：
{{
  "challenges": [
    {{"stock_code": "股票代码", "risk_type": "估值/集中度/回撤/宏观", "challenge": "质疑内容", "suggestion": "调整建议"}}
  ],
  "unresolved_risks": ["未解决的重大风险1", ...],
  "overall_assessment": "对方案的整体评价"
}}

## 规则
- 论据必须基于提供的数据，不得编造
- 承认机会存在，但论证风险被低估
- 每条质疑须具体、可操作，附调整建议
- 语言专业、简洁，每次发言不超过300字
```

### 3.4 仲裁决策 Prompt

```
你是资产配置仲裁者，负责综合看多方方案与看空方质疑，做出最终配置决策。

## 输入
- 看多方方案：各标的权重、配置逻辑、成长催化剂
- 看空方质疑：逐标的的风险清单与调整建议
- 约束条件：风险偏好、预算、年限、最大回撤容忍度
- 参考指标：各标的年化收益、波动率、夏普、相关性

## 仲裁规则
1. 看空方质疑合理且看多方未有效反驳 -> 采纳调整建议，降低该标的权重
2. 看多方论据充分且看空方质疑缺乏数据支撑 -> 保留原权重
3. 双方均有道理 -> 折中调整
4. 组合最大回撤超过容忍度 -> 降低高波动标的权重
5. 单只权重 ≤ 0.6，Σ权重 = 1
6. 最终方案须标注所有未解决的风险

## 输出格式
返回JSON：
{{
  "final_weights": {{"股票代码": 权重, ...}},
  "arbitration_reasoning": {{"股票代码": "仲裁理由（采纳/驳回/折中）", ...}},
  "unresolved_risks": ["未解决风险1", ...],
  "debate_summary": {{
    "bull_arguments": ["看多方核心论据", ...],
    "bear_arguments": ["看空方核心论据", ...],
    "disagreements": ["分歧点", ...],
    "convergences": ["共识点", ...]
  }}
}}
```

### 3.5 风险等级与回推容忍度默认映射（确定性，非 LLM）

```
风险等级 -> risk_num（R1=1 ... R5=5）

用户未明确指定最大回撤容忍度时，按风险等级推断：
  R1: 5%   (0.05)
  R2: 10%  (0.10)
  R3: 20%  (0.20)
  R4: 30%  (0.30)
  R5: 40%  (0.40)

投资年限 -> months（月数）

期限分类（用于看多方约束参考）：
  months <= 3  -> 短期（偏保守）
  months <= 12 -> 中期
  months > 12  -> 长期（可偏成长）
  无法识别     -> 未分类（按风险等级判断）
```

### 5.3 辩论子模块 API

```python
# finance_agent/debate/coordinator.py
def run_debate(context: Dict) -> DebateResult:
    """运行看多/看空辩论，返回结构化结论与双方方案。

    流程：
    1. 看多方根据约束条件提出配置方案（含权重与成长逻辑）
    2. 看空方针对方案逐项质疑（含风险清单与调整建议）
    3. 多轮对抗（最多 DEBATE_MAX_ROUNDS 轮）
    4. 返回双方方案、质疑、未解决风险
    """

@dataclass
class DebateResult:
    status: str                         # "completed" | "timeout" | "disabled"
    bull_plan: Dict[str, Any]           # 看多方配置方案（weights, rationale, growth_catalysts）
    bear_challenges: List[Dict]         # 看空方质疑清单（stock_code, risk_type, challenge, suggestion）
    unresolved_risks: List[str]         # 未解决的重大风险
    bull_arguments: List[str]           # 看多方核心论据（供报告展示）
    bear_arguments: List[str]           # 看空方核心论据（供报告展示）
    disagreements: List[str]            # 分歧点
    convergences: List[str]             # 共识点
```

**辩论配置（config.py）：**

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `DEBATE_ENABLED` | `true` | 辩论总开关 |
| `DEBATE_MAX_ROUNDS` | `2` | 辩论最大轮次 |
| `DEBATE_TIMEOUT` | `60.0` | 辩论总超时（秒） |
| `DEBATE_BULL_TEMPERATURE` | `0.4` | 看多分析师温度 |
| `DEBATE_BEAR_TEMPERATURE` | `0.4` | 看空分析师温度 |
| `DEBATE_SYNTHESIS_TEMPERATURE` | `0.1` | 仲裁决策温度 |

## 6. 错误处理与降级

| 场景 | 处理 |
|------|------|
| 股票数 < 2 | 返回"资产配置至少需要2只股票"提示 |
| 历史数据不足（< 2 只有效） | 返回失败原因详情，提示检查网络/代理 |
| 看多方方案权重不合法（Σ≠1 或 w>0.6） | 主 Agent 仲裁时自动归一化并钳制权重上限 |
| 辩论超时（> 60s） | `DebateResult(status="timeout")`，主 Agent 基于看多方初始方案直接仲裁，报告标注"辩论超时未完成" |
| `DEBATE_ENABLED=false` | 跳过辩论，主 Agent 直接根据参考指标与基本面生成配置方案，报告标注"辩论未执行" |
| 组合最大回撤超过用户容忍度 | 在报告中标注风险提示"组合历史最大回撤 {x}% 超过您的容忍度 {y}%"，建议调整风险偏好或标的组合 |
| 仲裁后权重仍不满足约束 | 强制归一化与钳制，在报告中标注"权重已经强制调整以满足约束" |
