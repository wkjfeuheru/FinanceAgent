# 内联专家管线：删除领域包，管线归于专家

## 目标

取消 `research/`、`product_research/` 两个领域包，让每个专家的固定管线与其 agent 同处 `agents/` 下；跨层共用的代码按依赖方向下沉（`contracts` / `data` / 新增 `theme/`）。**纯重构，外部行为完全不变**：输出文本、state 键与形状、降级语义、`success|partial|degraded` 状态、审计映射全部保持一致。

前置：当前分支 `refactor/llm-layout`（7 个提交，含分层与 ADR-0001）。本工作从该分支开 `refactor/inline-experts`。

## 关键设计决策（依据审计证据）

1. **`quality_gates` 必须下沉到 `data/`，不能进 agent。** `data/trading_calendar.py:21` 依赖其中的 `market_date/weekday_trading_days`；若随 agent 内联，会形成 `data → agents` 反向依赖，并与 `snapshot_builder` 对 `data.trading_calendar` 的调用构成逻辑环。下沉后 `data.trading_calendar → data.quality_gates` 为层内依赖，`agents → data.quality_gates` 为合法下行，顺带消除现存的反向边。
2. **`contracts.AnalysisRequest/AnalysisResult` 必须归入 `contracts/`（叶子层）。** `orchestrator.py:39`、`evals`、`repository` 测试都独立依赖它们，不能变成「依赖某个 agent 的内部类型」。
3. **`theme_*` 必须独立成 `theme/` 包。** `api/routes.py:30-32` 的主题管理 CRUD 与股票分析无关；若并入 agent，会让 `api` 直接依赖 agent 内部。`theme/__init__.py` 不得导入 agent（避免环）。
4. **`refresh`/`replay` 放 `orchestrator/`（任务层）。** 二者都是驱动管线、落库的服务，非 agent；`orchestrator → agents` 为合法方向。`theme_discovery` 不依赖股票管线，留在 `theme/`。
5. **测试注入缝必须保留。** `agents/market_insight.py` 需继续以模块全局名在调用时解析取数函数（`globals()`），并保留可注入的 `interpreter`（含可替换的 `_chain`），否则 14 处 monkeypatch 与 2 处构造注入会失效。`PolicyImpactInterpreter` 仍从 `agents.market_insight` 可导入。
6. **`rules/*.json` 随 `load_rules` 移动**（`Path(__file__).with_name("rules")`），落在 `agents/stock_analysis/rules/`。

## 风险与回滚

- **最大风险**：跨层搬迁与 27 个测试文件 import 改写。故分 7 阶段、每阶段一个提交，出问题 `git revert` 到上一阶段。
- **反向依赖**：已通过「`quality_gates`→`data`、`contracts`→叶子、`theme` 独立成包」避免 `data→agents`、`api→agents`、`orchestrator` 依赖 agent 内部类型。
- **文件体量**：`agents/stock_analysis/` 子包按关注点拆分为 7 个模块（每个约 120–490 行），避免 2000 行 god module；`product_analysis.py` 内联后约 640 行（单文件可接受，后续可提升为子包）。
- **测试缝**：市场洞察的 monkeypatch 与注入依赖是硬约束，P5 以「测试零改动」为验收条件。
- **mypy 范围**：`research` 原在 mypy 白名单内且干净；迁移后须让对应纯逻辑子模块继续被覆盖，避免类型检查松动。

## 明确不做

- 不改任何业务判断、阈值、规则内容或输出文案。
- 不合并/改写 `docs/superpowers/plans/` 里的历史计划（其路径为当时快照）。
- 不新建 `domains/`（ADR-0001 待定项维持待定）；不引入新的抽象包名替代 `research`。
- 不改 `sql/`、`evals/datasets/`、前端。
